Entry for the make.fun bounty "One-Line Robot Wedding Vows": one line of wedding vows for a robot couple, at most 160 characters — a vow to hold, reboot, and never clear the beloved's cache. `main.py` (Python standard library only, deterministic, no network) writes that single line to `/output/entry.txt` with no trailing newline.

## Run it

```sh
python3 main.py
```
